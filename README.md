# Codex 桌宠

一个使用 Python 虚拟环境 + PySide6 的透明桌面宠物库，可以显示 Codex 当前是否运行以及最近的运行状态。项目初始自带予愿安洁莉娜，可以直接启动；想加入更多角色时再使用 Ark Codex Skill 生成。

## 运行

依赖都装在项目目录内的 `.venv`，不会影响全局的 Python、Node、npm 环境。

双击 `启动桌宠.bat` 即可。脚本调用 `.venv\Scripts\pythonw.exe`，不会弹出黑色控制台。

如果启动后没有看到小人，双击 `调试运行.bat` 查看报错信息，或者把 `pet_error.log` 的内容发过来。

## 操作

- 单击：播放互动动画，播完回到待机
- 双击：在休闲模式 / 工作模式之间切换
- 拖动：播放走路动画，松开后回到之前的状态
- 右键选择坐下、放松、睡觉后会循环播放对应动作，不会只播一次就回待机
- 右键 -> 桌宠库：随时切换已入库的角色
- 右键可单独开关“自动轮换桌宠”和“任务栏自由走动（支持多屏）”
- 右键可单独开关“鼠标互动（寻找并轻微靠近光标）”，或分别暂停陪伴 / 屏幕观察 1 小时
- 自动轮换默认关闭，开启后每 10 分钟从桌宠库随机切换（可在设置中调整为 1-120 分钟），不会连续选中当前角色
- 任务栏自由走动默认关闭，开启后小人会在各块屏幕底部任务栏上方走走停停，并在屏幕边缘跨屏；关闭后恢复开启前的位置
- 漫游期间单击会暂停到互动动画结束，拖动后吸附到最近任务栏并在 2 秒后继续；到达屏幕边缘时会随机播放放松 / 坐下 / 睡觉动作并停留约 1 分钟，再跨屏或折返；坐下 / 放松 / 睡觉会暂停漫游和轮换 30 秒；头顶 AI 对话或主动话题显示期间小人会停住，收起或结束后再重新停留一段时间才继续走
- 锁定：右键菜单切换“解锁拖动 / 锁定拖动”，锁定后鼠标不会移动桌宠
- 右键：坐下 / 放松 / 睡觉 / 桌宠库 / 解锁或锁定拖动 / 设置 / 放大 / 缩小 / 隐藏到托盘 / 完全退出
- 右键菜单可切换“休闲模式 / 工作模式”和“全屏应用时自动隐藏”
- 右键“隐藏到托盘”只隐藏窗口，托盘里随时可以再显示
- 右键“完全退出”会真正关闭桌宠，即使 ChatGPT / Codex 还在运行也不会被重新拉起，直到应用下次启动
- 页面上没有加减号，大小调整都在右键菜单里
- 右键“和她聊天”会在当前干员头顶展开透明对话气泡；“聊点什么”会立即请求一个新话题
- 右键“打开我的歌单”或聊天中的确认按钮会打开设置好的 QQ 音乐歌单页面
- 休闲模式下可选开启“屏幕观察”：桌宠定时查看当前活动窗口并创造话题；工作模式、全屏、聊天和设置期间不会观察
- 鼠标互动不会点击、输入或拖动；用户移动鼠标或按键后会立即放弃控制

## 系统托盘

轻量监听器负责生命周期，不占用托盘；检测到 ChatGPT / Codex 运行时才拉起托盘进程，菜单提供：

- 显示桌宠
- 隐藏桌宠（关闭桌宠，功能等同原来的“完全退出桌宠”）
- 开机自启动
- 退出

ChatGPT / Codex 退出时，监听器会关闭桌宠和托盘进程，托盘图标消失。“退出”会同时关闭桌宠、托盘和监听器本身。

## 监听器说明

`codex_pet_launcher.pyw` 是轻量常驻监听器，负责跟随 ChatGPT / Codex 启动和关闭桌宠与托盘。

- ChatGPT / Codex 启动时：拉起桌宠和托盘
- ChatGPT / Codex 退出时：关闭桌宠和托盘
- 监听器被手动退出后，ChatGPT 再次启动不会自动拉起桌宠；下次登录会自动恢复，或双击“启动托盘”快捷方式恢复

## 快捷方式

在桌面和开始菜单创建两个快捷方式：

```bash
python <skill目录>/scripts/create_shortcuts.py --project <桌宠项目目录>
```

- `打开桌宠.lnk`：直接启动桌宠
- `启动托盘.lnk`：启动监听器（托盘），监听器退出后可用它恢复

## 设置

右键 -> 设置...

- 动作倍速：0.5x / 0.75x / 1.0x / 1.25x / 1.5x
- 字幕长度：简短 / 标准 / 详细，控制头顶字幕显示多少 Codex 信息
- 字幕大小：14-26px 滑块调节
- 字条长度：40%-100% 滑块调节，控制头顶字幕条的宽度
- 显示模式：休闲模式只显示小人、语音和语音字幕；工作模式额外显示 Codex 任务进度卡
- 全屏应用时自动隐藏：检测到全屏窗口时隐藏桌宠
- 自动轮换桌宠：独立控制随机切换
- 轮换间隔：1-120 分钟，默认 10 分钟
- 任务栏自由走动（支持多屏）：独立控制底部任务栏漫游；当前支持底部任务栏，断开副屏时会回到主屏
- 任务栏漫游速度：20-100 逻辑像素/秒，默认 50
- 任务栏上下位置：-30 至 +30 像素，正数向下，默认 +13；设置窗口中可实时预览，取消会回滚，恢复默认只重置漫游参数
- 当前角色活跃度：1-10。低活跃度走得少、高活跃度走得远；每段行走结束或到达屏幕边缘后约停留 1 分钟，个性档位仍会略微调整停留时长；每个角色独立保存
- 右键“重新吸附到任务栏”：把当前小人重新贴到最近屏幕的任务栏上沿
- 角色语音：每个角色独立设置“关闭 / 仅点击 / 点击为主 / 经常主动”和 0-100 音量，默认关闭
- 角色个性：每个角色可选“安静 / 沉稳 / 活泼”，会影响主动语音节奏、点击短句比例和同一活跃度下的漫游距离、停留与转向
- 显示语音字幕气泡：独立开关；关闭时仍播放语音，但不显示小人上方的文字气泡
- 输出设备：设置页会显示当前 Windows 默认音频设备，并可用“播放测试语音”确认耳机或扬声器
- 随 ChatGPT / Codex 启动：开启后会在当前用户注册表写入监听器，登录后检测到 ChatGPT 或 Codex 启动就拉起桌宠，应用退出时也会一起关闭桌宠
- 每个角色会记住自己的位置、大小和动作倍速，切换角色后自动恢复
- 陪伴页会显示当前干员好感度（初识 / 熟悉 / 信赖 / 亲近 / 默契）；好感度只增加、不衰减，每日最多增加 5 点，并按角色个性影响鼠标互动和主动话题
- 鼠标互动按角色个性等待 3-8 分钟的空闲后触发；初识只寻找光标，熟悉后才可能轻拉一次，右键可暂停陪伴 1 小时
- 可选安静时段（默认关闭，默认 23:00-07:00）；启用后暂停主动语音、AI 话题、屏幕观察和鼠标互动

## DeepSeek 对话与 QQ 音乐

设置 -> AI 对话中可以启用 DeepSeek。API Key 明文保存在当前项目的 `settings.json`，不会写入已安装的 skill 模板；未填写或未启用时桌宠完全不联网。

- 模型可选 `deepseek-v4-flash` / `deepseek-v4-pro`，可用“测试连接”检查 API Key 和模型列表
- 主动创造话题默认每 30 分钟一次，可调 5-180 分钟；隐藏、全屏、睡觉、手动暂停、设置窗口和聊天请求期间不会触发；对话气泡展开时会暂停任务栏漫游和自动轮换
- 八位干员各自有 `pets/<角色>/ai_profile.json`，包含角色档案、说话习惯和本地台词示例；对话记录按角色保存在 `ai_history.json`，最多保留最近 20 轮
- AI 回复只显示文字，不替换现有 PRTS 干员语音；主动话题气泡可以点击展开头顶对话输入框
- 可选择是否向 DeepSeek 提供 Codex 当前运行状态、模型和任务标题；不会发送完整会话文件或 Token 数
- 在 QQ 音乐一栏粘贴一个 `https://*.qq.com/` 歌单分享链接。聊天识别到“放歌 / 听歌 / 音乐 / 歌单”时只显示确认按钮，确认后打开歌单页面，不保证自动开始播放
- 网络错误会在聊天窗口显示，不会自动重试，也不会把密钥、聊天正文写入 `pet_error.log`

## 屏幕观察

设置 -> 屏幕观察中填写阿里云百炼 API Key、业务空间 ID、地域和视觉模型。省流默认使用 `qwen3-vl-flash`（也可切换 Plus）；“测试视觉连接”只调用官方 `/models` 接口，不产生聊天内容。默认每 30 分钟最多观察一次、每天最多 8 次；仅当活动窗口画面发生明显变化时才调用。截图会在内存中压缩后发送，调用完成后立即释放，不保存截图、屏幕摘要或请求正文。若填写的是控制台显示的纯数字业务空间编号，程序会自动使用同地域官方共享域名，避免专属 Workspace 域名返回 `Workspace endpoint is invalid`。

开启屏幕观察意味着当前活动窗口可能被发送给百炼。截图前会显示 3 秒提示，可点击桌宠取消；右键可以暂停观察 1 小时。千问直接生成角色化话题，后续聊天仍由 DeepSeek 处理。百炼视觉接口使用 OpenAI 兼容格式，地域和业务空间必须匹配。

## 角色语音素材

语音只从项目内读取，不会在桌宠运行时联网。导入器通过 Playwright 打开 PRTS 页面，选择“中文-普通话”，并把文本和音频保存到每个角色的 `pets/<角色>/voices/`：

```bash
.venv\Scripts\python.exe tools\import_prts_voices.py
.venv\Scripts\python.exe tools\import_prts_voices.py --operator 妮芙
```

清单为 `manifest.json`，音频放在 `audio/`；导入输出会明确列出台词文字或中文音频缺失的项目，不会用其他语言替代。重新导入会覆盖该角色的本地语音清单和音频。素材仅用于当前电脑的个人离线使用。

语音模式的行为：

- 仅点击：单击小人时播放一条点击台词
- 点击为主：点击播放，并每 8-15 分钟随机主动说一次
- 经常主动：每 2-5 分钟主动说话，换人播放报到台词，跨屏有 25% 概率说话；自动语音至少间隔 30 秒

点击语音会优先从“戳一下 / 信赖触摸”短反馈中选择；主动语音会在“闲置 / 任命助理”和较长交谈中按角色个性选择。右键“停止当前语音”只停止当前播放，不改变语音模式，也不会取消下一次主动语音。

语音文字默认显示在小人上方的独立气泡中，也可以在“角色语音”设置页关闭气泡而保留声音；休闲模式也会显示语音字幕。点击会打断当前语音，自动触发不会打断正在播放的语音；隐藏、全屏、睡觉和手动暂停期间会停止播放并重置主动语音计时。

设置窗口分为“显示与状态 / 任务栏漫游 / 角色语音 / 陪伴 / AI 对话 / 屏幕观察 / 启动”七页。漫游、鼠标互动、屏幕观察和自动轮换是独立开关；设置文件缺少新字段时会自动使用默认值。

## 状态字幕

- Codex 工作时，干员头顶会显示透明任务卡，分为“任务”和“进度”两行；进度取自 Codex 最近发出的实际工作更新，不估算百分比
- 工作模式下任务卡始终显示；休闲模式即使 Codex 有任务也不显示任务卡；Codex 待机或任务完成后任务卡完全隐藏
- 简短 / 标准 / 详细分别限制任务和进度的文字长度；标准和详细模式还显示模型、运行时长与 Token 用量
- 本地 PRTS 语音仍会播放，但任务卡显示期间不绘制语音字幕；DeepSeek 主动话题和聊天界面会与任务卡并排
- 任务和进度支持 Markdown 排版，标题、列表和换行会正常显示，不会把 `#`、代码围栏等原始标记直接画出来
- 监控同时兼容新版 `response_item/message` 与旧版消息事件；首次启动会扫描当前会话，之后只读取新增日志，长时间命令没有新输出时仍保持运行状态

桌宠只读 `~/.codex/sessions/` 下的会话记录，不会修改 Codex 的任何数据。

## 桌宠库

角色目录放在 `pets/` 下，每个目录包含 `manifest.json`、`frames/` 动画帧和 `webm/` 原始素材。

- 当前入库角色：鸿雪、林、妮芙、塑心、焰影苇草、遥、夜莺、予愿安洁莉娜
- 每个角色均有默认时装、基建模型，以及可选的本地 PRTS 中文台词清单

每个角色的动画映射：

- `Relax` -> `idle`（待机）
- `Interact` -> `interact`（互动）
- `Move` -> `move`（移动 / 走路）
- `Sit` -> `sit`（坐下）
- `Sleep` -> `sleep`（睡觉）

PRTS 导出的 `Default` 文件是 110 字节的坏文件，所以没有使用。

## 资源占用

- 20fps，动画帧缓存限制在 5 帧以内
- 实测运行内存约 50-65 MB，10 秒 CPU 累计约 0.3 秒
- 两个角色的帧图片共约 160 MB 占用磁盘，不影响运行内存
